
## 🛠️ Personal Configuration

A minimal, keyboard-driven setup focused on productivity and aesthetics.

This repo is managed by chezmoi.

### Core Stack
- **Shell:** zsh (with [Zimfw](https://github.com/zimfw/zimfw))
- **Terminal:** [foot](https://codeberg.org/dnkl/foot) (primary) + [ghostty](https://github.com/ghostty-org/ghostty) (alternative)
- **Multiplexer:** [ tmux ](https://github.com/tmux/tmux)
- **Windows Manager:** [ niri ](https://github.com/niri-wm/niri) (Wayland compositor)
- **quickshell:** [dank material shell](https://github.com/AvengeMedia/DankMaterialShell)
- **Editors:** [ Neovim ](https://github.com/neovim/neovim) + [ Zed ](https://github.com/zed-industries/zed) 
- **Music:** [ MPD ](https://github.com/MusicPlayerDaemon/MPD) + [ ncmpcpp ](https://github.com/ncmpcpp/ncmpcpp)
- **Browser:** [ qutebrowser ](https://github.com/qutebrowser/qutebrowser)
- **Document Viewer:** [ Zathura ](https://github.com/pwmt/zathura) (PDF/LaTeX)

### How to use it 

``` bash 
chezmoi --init --apply https://codeberg/fff-star/dotfiles.git
``` 

> [!WARNING]
> It may cover all your configs.
